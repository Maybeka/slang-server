# 完整模型重建前的释放

五类总目标仍未完成，本候选未交付 main。所有行为继续由默认关闭的 cooperative analysis 实验控制。

上一轮只释放数据流、查询和引用索引，旧 AST 仍与新模型共存。本轮在显式 setBuildFile 和同步源回收边界，先丢弃方法视图、文档语义缓存及引用 manager 内存的 Native 诊断路由。完整模型没有外部借用时，保存独立的符号源文件路径和实例选择值，再释放整个 ServerCompilationAnalysis。仍有 ActiveDesignContext 等借用时保留原模型。

释放后的旧工程仍可从当前文档重新构建。语法发现期间使用保存的路径提示，避免递归构建；新模型发布后清除提示。取消发生在模块索引或新模型发布前时，候选被丢弃，下一次查询重建。测试用 weak_ptr 过期确认旧完整 owner 确实销毁，比较恢复后的信号驱动、负载集合及实例选择。信号依赖枚举由指针集合产生，跨模型测试比较排序后的路径；首轮仅顺序不同的失败日志保留。

同一 Mac、同一 CVA6 完整环境，先完成一次 Native 更新并检查 UVM 和整个 DUT 的实际语义共享，再显式重载同一构建文件。编辑器中保留未保存的前导换行。该内存定位关闭局部更新，不能作为连续编辑验收。固定旧/新/新/旧顺序，各执行一次，不重采：
