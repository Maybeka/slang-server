基于 main `17c05257df985a451c8ee3fd9e0607e700f44bb7`，本轮受测二进制 SHA256 为 `9bcb0349e935f1bb7dacbbfe271775e4a064e9c695907fe1d2fbb91e61aafe05`；对照为上一已交付版本 `d7cefd5a8262cc59bdf1995e09b7d88d59e3d5f54609ab825cc6cdb4c3a8a5a3`。Mac 固定 34 组评估、192 项检查全部通过。该结果验收本轮组合，五类总目标仍进行中。实验默认关闭，没有新增固定防抖。

## 本轮实现

- 可丢弃模型的根绑定内部增加取消检查；层次、cone、实例和选择命令贯通请求上下文，索引及选择私有构建后提交。
- 同步最新编辑文本时省去一次冗余完整文件证明；最终查询与诊断仍逐次完整读取内容、核对 EOF、真实路径及最终文件版本。原生查询、语义命令和后台局部更新失败后的路径也承接输入认证，修复同长度、同时间戳依赖变化后的旧类型结果。没有跨请求成功证明缓存。
- 局部 task 诊断更新调用方时序检查；完成的 Native 分析为未编辑方法读取普通类句柄属性提供独立证据。新增非冻结 callee 的一般引用闭包尚未实现。
- Native 旧视图只持有必需源租约，避免持有整个 Driver；源存储弱引用去重，源码历史预算默认 64MiB、用户可设 1–4096MiB。预算仅计源历史，不是进程内存上限。位置表 Release 条目从 88B 降到 56B，独立元数据继续计量。
- 补全从首次回收前即使用代际标记；跨代际仅在 URI、打开版本、完整文本及物理 include 来源证明一致时重绑定，避免首次回收后补全详情丢失。
