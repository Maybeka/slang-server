## 实现与安全边界

完整模型、实例索引、活跃选择和冻结选择先私有构建，校验请求后统一提交。取消不替换旧完整视图；旧 ActiveDesignContext 可继续使用，重试构建最新文本。解析/索引及其临时回调的取消上下文继续传递。

完整语义的取消只进入明确可丢弃候选的外层遍历，不向共享 provider 或递归 lazy binder 继承。诊断准备可复用没有外部持有者的当前模型，避免重建相同根；共享旧视图仍使用独立候选。准备失败将当前模型标为 dirty，下一次重新构建，不能接着使用半完成语义。根绑定内部仍有约 129ms 的原子工作，这一项尚未完成。

普通非泛型 package 头文件查询可独立于完整 RTL 设计视图。泛型祖先、复杂类外方法归属、实际 RTL 实例及根层次相关语义仍保持原上下文。解析分析和实际依赖输入按同一代际构建及提交，避免首次认证重复解析不一致的图。

文件证明恢复严格逐文件读取，取消不划算的目录分组和 64KiB 分块策略。每次最终证明仍读取完整内容和 EOF，核对真实路径、文件类型、device/inode/size/mtime/ctime；最后路径版本必须匹配已读取的描述符。完整读取有取消检查。首次读取错误或观测到变化时，私有重载依赖并保留最新未保存文本。没有增加跨请求的读取成功缓存。
